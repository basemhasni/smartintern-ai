# SmartIntern AI v1.0.0

Projet de notes à publier seulement après les validations Jenkins feature et main,
la fusion de la PR et la vérification des digests Docker. Ce fichier ne constitue
pas une publication de release.

- Application web : comptes étudiant/entreprise, profils, CV privés, offres,
  candidatures, dashboards et administration.
- IA : matching explicable, Career Assistant, lettres de motivation, Skill Gap,
  RAG hybride et orchestration LangGraph, avec tests locaux déterministes.
- CI/CD : tests applicatifs et mobile, couverture, SonarQube/Quality Gate, Trivy,
  cinq images Docker, Compose smoke, E2E Chromium/API et performance k6.
- Kubernetes : déploiement Helm sur Minikube, migrations avant upgrade,
  Ingress HTTPS, vérification de persistance PostgreSQL et recovery des workloads.
- Observabilité : Prometheus, Grafana, cibles applicatives, métriques de trafic,
  datasource et dashboards vérifiés par les scripts de régression existants.
- Exploitation : pg_dump, restauration dans une base temporaire, contrôles
  migrations/pgvector, runbook et checklist de release.

Les images `v1.0.0` doivent être des alias des digests SHA du commit main validé,
sans reconstruction. Le cluster peut rester sur ces tags SHA immuables.

Consulter [la revue sécurité](SECURITY_REVIEW.md),
[la checklist](RELEASE_CHECKLIST.md) et [le runbook](../operations/RUNBOOK.md)
pour les limites connues et les conditions de publication. Cette release vise
la démonstration PFE locale ; un hébergement public exige une revue supplémentaire
des avis de sécurité et de la configuration d'exploitation.
