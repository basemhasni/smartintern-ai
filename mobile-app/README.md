# Mobile App - SmartIntern AI

Le dossier `mobile-app` est présent pour accueillir une future application mobile SmartIntern AI.

## Statut actuel

À ce stade, aucune application mobile complète n'est développée dans ce dossier.

## Objectif futur

L'application mobile pourra proposer la consultation des offres, le suivi des candidatures, les notifications, le résumé des conseils IA et un accès étudiant simplifié.

## À définir

- stack mobile finale ;
- architecture ;
- authentification mobile ;
- synchronisation avec `backend-api` ;
- écrans prioritaires.
